## 1. 추진 배경과 현안

- 외자 부품 Invoice 는 공급사마다 양식이 달라(열 순서 · 숫자 표기 · PO 적는 자리) ERP 업로드 엑셀로 옮기는 일을 손으로 합니다. 요청: 「INVOICE PDF 파일 > 엑셀 변환 — PO 번호 추가」.
- Invoice 번호가 적힌 건이 **항차등록까지 끝났는지** 확인하려면 A/N 의 B/L 과 대장을 오가며 맞춰 봐야 합니다. 요청: 「인보이스 번호가 기재되어 있다면 해당 건이 항차 등록 완료되어 있는지 B/L 과 매칭하여 확인」.
- 통관팀이 원산지증명서(C/O)를 요청하면 업체에 메일을 쓰고, 받을 때까지 따라가야 합니다. 요청: 「통관팀이 요청한 원산지증명서 요청 메일 관리 탭 > 업체에 메일 초안 작성 후 전달」.
- 같은 부서 권도연 님의 hd-project16 「외자부품 Invoice 엑셀 자동 변환」이 Invoice → 엑셀 방식(수량 × 단가 = 금액으로 칸 찾기)을 이미 보여 주었고, 강사가 두 과제의 결합을 약속했습니다.
- 회사 업무 PC 는 **사내 폐쇄망**이라 외부 AI · 클라우드를 쓸 수 없는 경우가 있어, 같은 기능을 인터넷 없이 도는 판으로 따로 둡니다.

## 4. 기능

### 4.1 Invoice PDF → 엑셀

- 엔진: data09-12 의 `js/invoice.js` 를 옮김(AI 부분만 뺌). hd-project16 의 생각 — 열 이름이 아니라 **「수량 × 단가 = 금액」이 성립하는 숫자 조합**으로 칸을 찾고, 유럽식 `1.234,56` 과 미국식 `1,234.56` 을 계산으로 가리고, 곱셈 자리 바꿈(`2 × 2480 = 2480 × 2`)은 표의 다른 줄이 정한 자리로 풀고, 맞지 않는 줄은 버리지 않고 「짐작」으로 넣어 사람이 고치게 함.
- data09-12 에서 더한 것: PO 번호(줄마다 · 「PO No. …」 구역 · 위쪽 한 번 — 출처 칸), Incoterms(CNF → CFR), B/L · AWB 번호, 적힌 Sub Total(없으면 Total − 부대비용)과 대조.
- 이 리포에서 더한 규칙 확인: 앞자리 0(`0,850` = 0.85, 천단위 아님), 점 날짜(`01.02.2026` = 일.월 — 애매하면 다른 해석과 함께 표시), 두 자리 연도, 한글 날짜.
- 결과 엑셀: ERP 업로드(부품 한 줄 = 한 행, 헤더 반복, PO No 칸) · Invoice 요약(합계 대조 · B/L · 항차등록) · 검산 확인 필요 · 부품으로 안 넣은 줄 · 읽지 못한 파일.

### 4.2 Invoice 번호 → B/L → 항차등록 확인

- B/L 한 건 = 한 기록. 상태: **대기**(항차등록일 없음 — A/N 전이면 「대기(A/N 전)」) · **완료**(항차등록일 있고 ETA 그대로) · **ETA 변경**(등록 때 ETA ≠ 지금 ETA → SRM 조정 필요).
- 찾는 순서(data09-12 의 invoiceLink 와 같음): ① A/N 엑셀의 Invoice 번호가 같은 B/L → ② Invoice 의 PO 가 든 B/L → ③ 대장 PO 의 B/L → ④ Invoice 에 적힌 B/L. ①로 찾으면 PO 로만 걸린 다른 B/L(분할 선적)은 뺌.
- 대장의 항차등록일은 **PO 한 줄의 값**이라(PO 가 B/L 여럿에 나뉘면 다른 B/L 의 날짜) B/L 상태로 쓰지 않음 — data09-12 예시에서 실제로 EX4500010008 의 대장 등록일이 다른 B/L(EXAW261002)의 날짜였음(테스트로 고정).
- 번호 하나 · 여러 번호(엑셀 열 붙여 넣기) 확인, 결과 엑셀. 완료 표시 · 조정 ETA 반영 · 고치기 · 지우기는 기록에 덧붙임.

### 4.3 원산지증명서 요청 관리

- data09-12 의 `js/co.js` 를 옮김: 요청 → 메일 작성 → 업체에 요청 → C/O 수령 → 통관팀 전달(· 취소), 상태마다 날짜, 이력은 덧붙이기만.
- 문안 2종(첫 요청 · 재촉)을 설정에서 고침. 빈칸 `{REF} {CO_TYPE} {CO_LIST} {DUE} {SENT_ON} {CONTACT} {SUPPLIER} {CODE} {SENDER} {DEPT} {COMPANY}`.
- 기한 경고: 기한 지남 · 3일 안 · 요청 후 2일 넘게 업체 미요청 · 수령 후 통관팀 전달 전.
- 번호로 채우기: Invoice 번호 → A/N 엑셀의 B/L · PO → 대장 업체 → 연락처 목록(이름 비교는 회사 꼬리말 · (예시) 표시를 떼고 6글자 이상).

### 4.4 Python 폴더 일괄 변환

- `python/invoice_rules.py` = `js/invoice.js` 의 Python 판(표준 라이브러리만), `python/invoice_to_excel.py` = 명령줄.
- PDF 글: pypdf 5.9.0(순수 Python, data09-15 와 같은 파일) layout 방식 — 칸 사이 띄어쓰기를 살림. 엑셀: openpyxl 3.1.5. 둘 다 `vendor/wheels/` 를 설치 없이 불러옴(없으면 설치된 것을 씀).
- 스캔본 · 깨진 PDF 는 멈추지 않고 「읽지 못한 파일」 시트에 이유와 함께 적음.

## 10. 확인이 필요한 것 (수강생께)

1. 사내 PC 에서 이 폴더를 **파일로 여는지(더블클릭), 사내 웹서버에 올릴 수 있는지** — 스캔본 글자 인식은 http 로 열 때만 됩니다.

| 업체 메일 | 첫 요청 · 재촉 문안 모두 해당 건이 있으면 목록 줄에 B/L Date, `{RETRO}` 자리에 소급 발급 요청 문장(기본: 「… issue the certificate retrospectively and mark it "ISSUED RETROSPECTIVELY"?」). 예전에 저장한 문안에 `{RETRO}` 가 없으면 대상 목록 뒤에 넣음 |
