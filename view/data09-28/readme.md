## 처음 쓰는 법 — 브라우저

1. 파일 묶음(ZIP)을 **aebon@dreamitbiz.com** 으로 문의해 받아 사내 PC 에 풀고 `index.html` 을 더블클릭합니다(설치 없음). 온라인 미리보기: https://aebonlee.github.io/data09-28/
2. **Invoice → 엑셀** — Invoice PDF 를 끌어 놓습니다. 먼저 「예시 Invoice 2종으로 해 보기」를 눌러 보세요. 수량 × 단가 = 금액이 안 맞는 줄은 빨갛게 표시되니 칸을 고친 뒤 「ERP 업로드 엑셀 내보내기」.
3. **항차등록 확인** — data09-12 의 「도착 통지(A/N)」 · 「관리 대장」 화면에서 내보낸 엑셀을 올립니다(예시: 「예시 엑셀 2개로 해 보기」). Invoice 번호를 넣으면 B/L 과 **대기 / 완료 / ETA 변경** 을 보여 줍니다. 여러 번호를 붙여 넣어 한꺼번에 확인할 수도 있습니다.
4. **원산지증명서** — 통관팀 요청을 적고 「번호로 업체 · PO · B/L 채우기」 → 「메일 초안」 → 메일 프로그램으로 열기 · 복사 · .eml 저장 → 「보냈음으로 표시」. 회신이 없으면 「재촉 메일」.
5. **설정** — 보내는 사람, 업체 연락처(Contact List 엑셀 가져오기), 메일 문안(첫 요청 · 재촉), 사내 PO 번호 모양, 백업.

스캔본(글자 층 없는 PDF) · 사진은 이 PC 안 글자 인식(OCR, 한국어 + 영어)으로 읽습니다. **글자 인식은 파일로 연 화면(file://)에서는 브라우저가 막아 동작하지 않습니다** — 사내 웹서버에 올리거나 폴더에서 `python -m http.server 8000` 을 실행하고 http://localhost:8000/ 으로 열어 주세요(실측은 [vendor/tesseract/README.md](vendor/tesseract/README.md)). 그 밖의 기능은 파일로 열어도 됩니다.

## 엑셀이 안 올라갈 때

회사 PC(D드라이브 등)의 엑셀이 고르기 창에 안 보이거나, 골라도 「파일을 읽지 못했습니다」가 나오면 아래 순서로 해 보세요(2026-10-01 추가, 외부망 판 data09-12 와 같은 보완).

1. **파일이 창에 안 보이면** — 파일 고르기 창 오른쪽 아래 형식을 「모든 파일(*.*)」로 바꾸거나, 엑셀을 올리는 단추 옆의 **「모든 파일에서 고르기」**를 누릅니다. 창 왼쪽의 「내 PC → D:」 로 가면 D드라이브·바탕화면 어디든 고를 수 있습니다.
2. **「문서보안(DRM) 파일」이라고 나오면** — 회사 문서보안 프로그램이 파일을 암호화해 둔 것이라 브라우저는 읽을 수 없습니다. ① 엑셀에서 열어 「파일 → 다른 이름으로 저장 → CSV(쉼표로 분리)(*.csv)」로 저장해 그 CSV 를 올리거나 ② 문서보안 해제(반출 승인)를 받은 뒤 올립니다.
3. **「암호가 걸린 파일」이라고 나오면** — 엑셀에서 열어 「파일 → 정보 → 통합 문서 보호 → 암호 설정」에서 암호를 지우고 저장한 뒤 올리거나, CSV 로 저장해 올립니다.
4. CSV 는 엑셀을 올리는 모든 곳(항차등록 확인의 data09-12 엑셀 · 설정의 Contact List)에서 받습니다. 「CSV(쉼표로 분리)」(한글 CP949)와 「CSV UTF-8」 둘 다 한글이 깨지지 않게 읽습니다. Invoice 의 `.txt` 도 같습니다.

여러 파일을 함께 고르면 읽을 수 있는 파일은 그대로 읽고, 못 읽은 파일만 따로 알려 드립니다. 파일 머리 가리기는 이 PC 안에서만 하며(`js/filecheck.js`), 파일로 연 화면(file://)에서도 됩니다.

## 처음 쓰는 법 — Python (폴더째 한꺼번에)

Python 3.8 이상만 있으면 됩니다. PDF 읽기(pypdf)와 엑셀 쓰기(openpyxl)는 `vendor/wheels/` 에 들어 있어 따로 설치하지 않아도 됩니다.

```
python python/invoice_to_excel.py "C:\Invoice\9월"
python python/invoice_to_excel.py "C:\Invoice\9월" -o 9월_Invoice.xlsx --ledger 관리대장.xlsx
```

- 폴더 안의 `.pdf` · `.txt` 를 모두 읽어 엑셀 한 파일(기본: 그 폴더의 `Invoice_ERP_날짜.xlsx`)을 만듭니다. 시트: ERP 업로드 · Invoice 요약 · 검산 확인 필요 · 부품으로 안 넣은 줄 · 읽지 못한 파일.
- `--ledger` : data09-12 에서 내보낸 관리대장(PO 번호 칸)을 주면 사내 모양이 아닌 PO 번호도 찾습니다. `--po-regex` : 사내 PO 번호 정규식. `-r` : 하위 폴더까지.
- 스캔본 PDF 는 명령줄에서 읽지 못하고 「읽지 못한 파일」에 적힙니다 — 브라우저의 글자 인식으로 읽어 주세요.
- 브라우저와 **같은 규칙**입니다(`python/invoice_rules.py` = `js/invoice.js`, 같은 기대값 표로 검사).
